# Licensed Asset Sourcing

Use this reference before searching for or downloading third-party photos and videos.

## Asset plan first

Define roles before searching: hero, offering, atmosphere, process, detail, location context, social preview, video poster, and cinematic source. Write one focused query per role using subject, setting, lighting, composition, orientation, and desired negative space.

Download only selected assets that have a clear page role. Avoid building an undifferentiated stock library.

## Pexels workflow

- Pexels media is provided under the Pexels license; it is not public domain.
- Confirm the current license and API guidelines at execution time.
- For manual downloads, preserve the asset page URL, creator, download date, and license note even when attribution is optional.
- For API use, use an authorized API key, respect rate limits, retain the asset ID and creator data, show the required Pexels link, and credit creators when the current API guidelines call for it.
- Do not imply that an identifiable person, depicted brand, interior, storefront, dish, haircut, construction project, product, or customer belongs to or endorses the prospect business.
- Do not use stock media as the business logo, trademark, trade name, or proof of actual work.

## Representation labels

Classify every asset:

- `authentic`: supplied or approved by the business for this use.
- `representative`: licensed stock illustrating a category or mood; safe for a private concept but replace when authenticity matters.
- `generated`: AI-created concept media; record its origin and do not present it as documentary evidence.

For a prospect concept, choose representative media that matches the category and design direction while explicitly listing what should be replaced after client engagement. For production, authentic media is preferred for the hero, team, location, portfolio, menu, services, and trust sections.

## File handling

Store local copies in the project's asset structure, use stable descriptive names, avoid hotlinking, and record source, creator, license, attribution, dimensions, role, crop, and representation status in the asset manifest. Optimize derivatives without deleting the source record.
