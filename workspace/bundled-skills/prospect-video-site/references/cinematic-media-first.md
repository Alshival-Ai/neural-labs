# Cinematic media-first presentation contract

This workflow selects `$website-template-1` for its UI/UX guidelines and visual
guardrails. Read the template's
[media-first presentation](../../website-template-1/references/media-first-presentation.md)
for geometry, interaction behavior, accessibility and machine-checkable hooks.

Keep `experience.presentationProfile: cinematic-media-first` and
`experience.motionPolicy: auto` in `WEBSITE-BRIEF.json`. Preserve these hook names
for the existing `qa-site.mjs` checks. The prospect workflow owns its asset limits,
CSP, evidence records, build gates and release verification.
