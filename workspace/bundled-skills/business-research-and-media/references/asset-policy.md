# Asset choices

Prefer suitable user-provided or authentic assets with a usable source and rights.
For remaining roles choose a strong typographic/original-graphic composition or
appropriate licensed representative media. Respect the user's asset preferences;
stock is optional, and no provider or paid API key is required.

Before sourcing, specify the role, subject, composition, palette, aspect ratio,
desktop/mobile crops and relationship to other images. Inspect selected assets
at their intended size. Avoid images that falsely imply they show this business's
staff, clients, premises or past work. Preserve provenance and required credits.

Use generated representative imagery only when the user requests it and an
appropriate configured tool is available. Do not install providers, buy credits,
require a generation attempt before using licensed stock, or assume that a model
connection includes an image-generation API. If unavailable, continue with the
available assets and explain any remaining gap.

In MEDIA.json record `origin: authentic|generated|stock|original-ui`, source,
usage basis, local derivatives, intended role and authentic/representative status.
Keep original files and private evidence outside public output. Record actual
limitations; do not manufacture provider calls or failed attempts as evidence.
